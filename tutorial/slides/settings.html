Edit with nano config/config.yaml; each setting has a comment. Re-running redoes only the affected steps · 15

You can leave every other setting alone for a first run. The ones on this slide are the ones worth knowing. At higher coverage, ask for more supporting reads and better control coverage, which cuts false positives. With several mutant samples that should all carry the same mutation, set mutant_rule to all. To compare settings, set a new output folder, so both runs stay side by side. After editing, run ./run_wgs.sh again; the pipeline works out which steps are affected and redoes only those. Changing comparison settings, for example, takes about 20 minutes.

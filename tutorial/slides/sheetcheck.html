Edit the sample sheet with nano, a simple text editor in the terminal: arrow keys to move, Tab between columns, Control-O then Enter to save, Control-X to leave. If you prefer Excel, fill in the four columns there and save as tab-delimited text. Then run the check. It prints one ok line per sample, with single-end or paired-end, so you can confirm the files were understood. If something is wrong it says exactly what: the two most common messages are a missing column, which almost always means spaces instead of tabs, and file not found, which means a typo in the path.

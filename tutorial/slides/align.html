2 · Align

Each read is matched to its best place in GRCz11, about 1.4 billion letters.

Each placement gets a mapping quality: how sure it is. Reads in repeats score low; variant calling ignores reads below 20.

Ours: 98.4% of reads placed

3 · Mark duplicates

Reads that start at the same place on the same strand are PCR copies of one fragment. All but one are flagged.

Without this, one PCR error copied ten times could pose as a real variant.

Ours: 12.8–13.2% duplicates (fine)

Step two places every read on the reference genome with bwa-mem2. Each placement comes with a mapping quality, a measure of how sure the aligner is. A read from a repeat could belong to several places, so it scores low; the variant caller ignores reads below 20. Step three marks duplicates: during library PCR one DNA fragment can be copied many times, and the copies all start at the same position. Only one is counted, so a PCR error cannot masquerade as a variant supported by many reads. After both steps, usable coverage is what is left: 2.8-fold and 3.4-fold here.

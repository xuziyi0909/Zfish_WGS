About two hours for two samples

A run can be stopped with Ctrl+C and resumed later with the same command · 17

Here is what to expect while it runs. The first run in a new folder spends about an hour downloading the genome, the known-variant list and protein sequences; later runs skip that. Cleaning and alignment take the longest and scale with the number of reads. The last block, annotation, comparison, the checks and the report, takes about half an hour. To check progress, reattach with screen -r wgs: Snakemake prints how many steps are done. The step count shown is an example. Every run also writes a complete log in results/logs.

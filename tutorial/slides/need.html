Before you start

Three things to have ready

Sequencing files

The .fastq.gz files from the core, for at least one mutant and one control. Paired-end (R1 + R2) is best; single-end works.

A server login

Log in to the lab server with ssh (Terminal on a Mac, PowerShell on Windows). All the software is already installed there.

Your own copy

One pipeline folder per experiment. Copy the FASTQ files into its data/raw folder (Cyberduck or FileZilla work well).

Your time: about 15 minutes

Computer time: about 2 hours, longer for deeper data

First run only: about 1 hour of downloads

Step-by-step instructions: the pipeline guide, “First-time setup” · 9

Three things. First, the FASTQ files: these are the raw reads from the sequencing core. Ask the core for both read files, R1 and R2, of every sample; in our example only one file per sample was available, which halves the data. Second, a login to the lab server. Third, your own copy of the pipeline: one folder per experiment, so results never mix. The very first run in a new folder also downloads the zebrafish genome, the list of known variants and protein sequences from other species; if you copy the reference folder from an earlier project, that step is skipped.

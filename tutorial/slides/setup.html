Setup happens once per experiment and takes about five minutes. Log in to the lab server with ssh; on a Mac use the Terminal app, on Windows PowerShell. The password does not show while you type. Then make your own copy of the pipeline in the projects folder, one copy per experiment, so results never mix. If someone already prepared the genome in an earlier project, copy their reference folder into yours: that skips about an hour of downloads on the first run. Finally run the check: every line should say ok.

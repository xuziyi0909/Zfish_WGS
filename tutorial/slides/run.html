Step 4 · Run

Start it inside screen, then walk away

screen -S wgs # a session that outlives logout
./run_wgs.sh # checks, then runs everything
Ctrl+A, then D # leave it running; log out
screen -r wgs # later: come back to check

Finished! Open this file in a web browser: results/report.html

Stopped part-way?

Fix the cause and run ./run_wgs.sh again. Finished steps are skipped.

How long?

About 2 hours for two samples; about 1 hour of alignment per 100 M reads.

Each run writes a full log to results/logs/ · 16

Running is one command. Start screen first, so the run keeps going after you close your laptop. The script first checks the software and the sample sheet, then runs every step. Press Control-A then D to detach, and log out. screen -r wgs reattaches. When it finishes it prints where the report is. If anything stops it, a power cut or a typo in the sample sheet, fix it and run the same command again: the pipeline remembers which steps are done.

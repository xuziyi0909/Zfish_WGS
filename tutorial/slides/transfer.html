Step 1 · Your sequencing files

Put the FASTQ files in data/raw

From your computer

  1. Open Cyberduck or FileZilla
  2. Connect with SFTP, using your server login
  3. Go to my_wgs_project/data/raw
  4. Drag the .fastq.gz files in

Already on the server

For example, a zip from the sequencing core:

mkdir -p data/raw
unzip "/path/to/file.zip" -d data/raw
ls data/raw

Keep R1 and R2 in the file names. You need to know which file is read 1 and which is read 2.

One sample on several lanes? Join the lanes, keeping R1 and R2 apart:

cat S1_L001_R1_001.fastq.gz S1_L002_R1_001.fastq.gz > S1_R1.fastq.gz

Avoid spaces in file names: rename with mv "my file.fastq.gz" my_file.fastq.gz · 11

Step one is getting the raw files into the data/raw folder of your copy. From your own computer, a file-transfer program like Cyberduck or FileZilla is easiest: connect with SFTP using the same login, then drag the files in. If the core delivered a zip that is already on the server, unzip it straight into data/raw. Two things to watch: keep R1 and R2 in the names, and if one sample was sequenced on several lanes, join the lane files first, read 1 with read 1 and read 2 with read 2. Gzipped files can simply be concatenated.
